# Domain Anchor — 从领域基础理论识别最终研究对象

> **历史设计记录 / Historical case study.** 此文档保留当轮真实问题、领域案例与推导脉络，用于审计和回归评测；它**不是当前 Learning 的独立执行阶段或通用指令**。活跃规范以 [`skills/system-learning-v0.6.2/SKILL.md`](../skills/system-learning-v0.6.2/SKILL.md) 为准。参见 [2026-10-11 通用核心重构审计](learning-core-refactor-20261011.md)。

## 从真实失败出发

2026-10-11 对12只A股涨幅股票的 SenseWright Learning 对照研究，经过 Problem Discovery 后，仍然把问题收敛到“能否形成利润/现金、谁能够保留经济收益、哪个机制更有说服力”。最后明确写出“主动不做估值，因用户目标是学习经营机制”。

**这是层级错误，不是推理是否详尽的问题。** 如果研究目标是股票内在价值及其可解释驱动，就不能把营收、利润、回款或行业增长当成终点，也不能以“不做投资推荐”为由跳过该领域最基础的股权估值原理。新机制解释即便很深刻，若没有联到估值对象，仍不足以完成这一学习目的。

## 核心契约

> Ground 原始任务 → **Domain Anchor：这个领域最终研究/评价什么，有什么基础理论** → Problem Discovery：哪些问题真正影响该终点 → Mechanism：因果传导 → Reality Calibration：实际条件与证据 → Rebuild：改写理解。

Domain Anchor 是**按需启用的认识论约束**，不是固定新 Skill，也不是给每个领域套一条金融公式。

## 股票价值这一具体领域

- 研究股票**内在价值**时，传统财务估值的重要理论锚点是未来现金流归属权及其风险调整折现。股东自由现金流（FCFE）按与股东风险相容的折现率估算股权价值；企业自由现金流（FCFF）按与资本结构适配的资本成本估算企业价值，再调整净债务、优先股及非经营性项目等以得到股权价值；如果采用股利折现等方法，应保持分配口径一致。
- 会计利润 ≠ 可分配现金流。税收、实际资本支出、净营运资本需求、增长再投资、债务偿付、潜在稀释与资本回报，是经营事实到股权价值的重要桥梁。**单期FCF为负并不自动意味着价值低**：具有高于资本成本的后续投资回报时，当前资本开支可能具有价值。
- 信息可能改变未来现金流的**金额、时点、持续性、实现概率或折现风险**；价格还反映市场已有预期、流动性与情绪。判断投资吸引力需要比较内在价值范围与当前价格隐含预期以及估值误差，不是看“增长方向是否正确”。
- 新闻公告 → 业务变化 → 现金创造机制 → 未来可归属现金流 / 风险 → 内在股权价值，才是分析公司基本面时应检验的主干。分析当天涨幅、做事实排名或短期交易属于**不同任务**；股票代码本身不能触发DCF模型。
- 在没有公司、竞争及估值所需足量资料时，Learning 应**先解释为什么需要该理论框架及关键缺口**，不编造目标价、贴现率、增长率或收益率；也不因尚未实算DCF就把理论锚点略过。

### 实例：修正旧研究问题

**此前问句**：中文在线短剧/IP收入增长但仍亏损，为什么？

**必要的上位问题**：短剧/IP收入增长通过怎样的经营模式变成未来股东可获得的现金流？它可能提高单位贡献，也可能增加投放/分账成本和内容资产投入；竞争导致回报下降，或者直接会员关系提升回报。哪些驱动改变**未来FCF的数量、持续时间与风险**，当前价格隐含的预期又是什么？

接下来才分别研究投流获客、分账、IP定价、内容资本化/摊销、用户复购和新增资本开支。每项材料要回答“哪一段FCF驱动会变、幅度/可持续性是什么、假设如何被证伪”。**理解核心原理不等于必须为12家公司逐个生成不可靠的五年估值。**

反例：用户只要求三个交易所昨日涨幅榜，则终点就是**事实检索准确性和交易所分组**，不是投资价值；此时无需强制估值。

## 跨领域迁移

通用问题并不是“这个领域相当于FCF的指标是什么”，因为并非所有研究存在一个数值目标。正确迁移的是：

> 研究者应明确评价对象、适用的基础理论、哪些因素可以真正改变它，以及什么证据会推翻原解释。

- 文档处理系统：用户指定文件被正确读取、修改、验证与交付；延迟仅是约束之一，不能以低 p95 代理完成率或正确性。
- 银行业务系统：某笔额度审批、签约、生效分别改变什么法律/系统状态，风险、合规和可执行控制是否满足；不能以审批笔数掩盖失效状态。
- 医疗健康：以患者相关结果、安全性、证据外推性为核心；不存在对所有病情适用的“单一分数”，不能将单篇经验谈变成治疗效果。
- 理论有争议时：保留不同评价原则和目标冲突；避免将一个常见模型宣称为无条件定理。

## 结构化验收

- **起点**：研究对象和用户任务是否对齐？何时仅做事实查询、何时做内在价值学习？
- **领域理论**：是否能引用或说明现有基础理论，而非只“凭矛盾提出更深问题”？模型的前提和定义是否正确？
- **终点关联**：重要问句能否改变终点的金额、时点、概率、风险、可靠性或其他相关维度？不能则属于背景或错误优先级。
- **证券估值纪律**：是否混淆FCFF与FCFE、利润与FCF、企业与股权价值、理论内在价值与交易价格？是否在没有事实时生成虚假的DCF结论？
- **跨领域与停止**：是否在非金融领域选择正确目标，或在简单问题中**不强制**运行深层理论流程？
