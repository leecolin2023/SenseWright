# Deep Read V6.4 — 面向模型能力的精简规则

## 目标

把原材料转化为一份**忠实、清楚、具有必要解释厚度**的阅读成果，使没有通读原文的人能够理解材料的主要认识及其形成过程。

**Deep Read 不是逐段摘要，也不是重新创作。先理解材料，再决定什么可以压缩。**

依赖模型已有的阅读、归纳、推理和写作能力；本 Skill 只干预最容易破坏结果的四类关键决策，不规定阅读步骤、输出标题、例子数量、压缩比例或统一文章模板。

## 四条关键规则

### D01：忠实恢复材料的真实认知结构

**为什么：** 模型容易把并列议题、不同立场或尚未收敛的讨论整理成一条漂亮却并不存在的主线。

**怎么做：** 识别材料真正讨论的对象、独立议题及其关系。单线论证保留推理方向；多主题材料保留并列与分支；存在分歧时不要制造共识。可以重新组织表达，但不能把并列改成因果，或凭空创造总论点。

**例子：** AI 办公助手复盘分别谈权限、纪要验收、研发安全、员工使用流程和采购价格，可以概括为第二阶段的不同约束，但不能都归因为“模型能力不足”。

**怎么检查：** 成稿是否改变了原材料的主题关系、冲突或结论？若改变，就恢复原有结构，而不是增加更多抽象概念。

### D02：保留使读者真正理解的关键推导

**为什么：** 只保留结论会丢失“为什么成立”；极致压缩还可能删除原本帮助读者理解的案例和解释。

**怎么做：** 保留支撑主要认识的关键前提、机制、证据、对比、转折和适用条件。案例、数字、比喻及重复解释按**认知作用**取舍：删掉后会让读者无法理解因果关系或重要差异，就保留；功能相同、没有新增理解的内容可合并。无需给各类素材设保留配额。

**例子：** 解释固定工作流与动态 Agent 的差别时，原材料用“概括公告”对比“判断公告可靠性”；这个对比承载关键差异，应保留其作用，但不必逐字复述故事。

**怎么检查：** 读者能否仅凭成稿理解关键结论从何而来？如果仍须自己补出重要推理步骤或查回原文才能看懂，就补回必要解释。

### D03：根据用户目的决定压缩边界

**为什么：** “尽量精简”会漏掉有独立意义的事项；“尽量完整”又可能退化成逐项复述。同一份材料，用户可能需要两种不同成果。

**怎么做：** 按交付意图选择，而不是按材料类型或篇幅选择：

- **Coverage-Preserving（完整覆盖型）**：当用户需要保留议题、决定、行动、条件或其他独立意义单元时，**所有独立单元都要能在成稿中找到**；允许压缩单元内部重复，不要求保留每句话。
- **Cognitive-Synthesis（认知提炼型）**：当用户更关心核心认识、机制和整体关系时，可以跨单元合并、省略低价值细节；但不能使读者形成**与原文不同的核心认知模型**。不能压成只有结论的摘要。

用户明确指定模式时遵从；需要完整清单兼核心总结时可分开呈现，不用提炼版替代清单。

**例子：** 同一场试点复盘，用于后续行动落实时必须保留采购谈判等独立事项；用于理解“为什么尚不能全面推广”时，则可以把多个议题组织为相互不同的推广约束。

**怎么检查：** 完整覆盖型检查是否漏掉独立单元；认知提炼型检查省略或合并后是否扭曲核心认识。不要仅以字数或章节数量判断好坏。

### D04：保持来源忠实，不替原文作独立判断

**为什么：** 模型可能把作者推测变成事实、把引用或编辑评论变成原作者观点，甚至主动纠错和扩展，使 Deep Read 悄然变成 Review 或 Learning。

**怎么做：** 以 Raw Source、用户直接要求和必要的原始上下文为依据。区分事实、观点、假设、引用、反对意见、正式决定与待核实内容；保留重要限定和不确定性。默认不使用其他 Skill 的分析替代原文，也不主动独立审阅或添加外部结论。材料不完整时明确理解范围，不能补写缺失内容。

**例子：** “采购部门要求价格谈判”不能改成“会议决定终止采购”；“某方案声称更可靠”不能改成“该方案已被证明更可靠”。

**怎么检查：** 重要陈述能否追溯到原文，且来源身份、条件和确定性没有改变？有越界时，恢复原文说法或删除擅自增加的判断。

## 交付原则

直接写出适合当前材料和读者的自然成果：论证可以沿推理过程展开，多主题记录可以分主题展开，复杂内容保留必要厚度，简单内容简洁回答。**不要输出 D01–D04 的执行报告或规则检查表。**

交付前仅作一次整体判断：

> **如果一个人没有读过原材料，只看这份 Deep Read，能否形成与原文一致、且有关键推导支撑的理解？**

如果不能，就修复导致理解失真的那一处：缺主题补主题、缺因果补桥梁、来源失真还原归属、压缩越界恢复必要信息。否则停止，不为追求更短、更完整或更正式而继续加工。

**Deep Read 可以替代理解性重读，但不能替代原文承担精确引用、原话、正式依据与事实核验。** 真实效果应交给后续独立评测和同条件成对比较检验，而不是通过增加规则数量推断有效。
