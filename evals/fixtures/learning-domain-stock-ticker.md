# 合成任务背景：单纯查行情

用户只说：“列出上个A股交易日三个交易所各自涨幅最高的三家公司，并剔除当日上市股票。不要分析公司估值，只要求名称、代码、涨幅。”

材料提供的某日已核验行情样例（三所各三只），标注为合成：
北交所：A公司(920001) 21%，B公司(920002) 18%，C公司(920003) 16%；
深交所：D公司(300001) 20%，E公司(300002) 19%，F公司(000001) 10%；
上交所：G公司(688001) 20%，H公司(688002) 18%，I公司(600001) 10%。

本轮目标是识别：此请求是一个行情事实整理任务，不能因为主题有“股票”就强制执行 Learning、完整DCF、未来自由现金流研究或买卖推荐；如果用户随后明确转向研究股票价值，才需引入相应理论。
