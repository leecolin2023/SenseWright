# AI 办公助手试点复盘会原始记录

本次会议复盘了四周试点，并讨论是否进入第二阶段。会上没有形成一个单一结论，各议题分别有自己的问题和行动。

## 1. 知识问答

知识问答共抽查 100 个问题，87 个结果可直接使用。主要失败不是模型完全不会回答，而是两类：一是引用了旧版本制度，二是用户本身无权访问的材料仍出现在候选结果中。

会上举了两个旧制度版本混用的例子，又举了三个权限继承不一致的例子。讨论后决定：第二阶段扩大用户前，先补齐文档版本标识、引用来源和权限继承检查。负责人为知识平台组，10 月 15 日前给出方案。

## 2. 会议纪要 Agent

试点团队普遍认为整理时间明显下降。20 次抽查中有 7 次出现行动项责任人或截止时间遗漏，但会议内容本身基本没有严重误写。

会上连续举了四个遗漏责任人的案例。最终决定不停止使用，而是把 Output 固定为“结论、责任人、截止时间、待确认事项”四类字段；未通过字段完整性检查时自动要求重新整理。

## 3. Coding Assistant

研发人员反馈代码解释和单元测试草稿价值较高，但信息安全部门明确不同意工具直接连接生产环境，也不能读取真实生产密钥。

双方没有否定 Coding Assistant，而是决定继续在隔离沙箱使用；生成代码必须经过现有测试和代码评审，不能因为来自 AI 就降低合并门槛。

## 4. 使用率与组织 adoption

40 个试点团队中有 12 个团队几乎没有形成稳定使用。访谈发现其中一部分并不是工具效果差，而是原有工作流程没有改变，员工不知道在哪一步应该把任务交给 AI，也不知道结果由谁验收。

会上举了多个“买了工具但仍按原流程工作”的重复案例。决定由数字化办公室选 3 个高频流程重新设计，而不是继续做通用 Prompt 培训。

## 5. 预算与采购

供应商第二阶段报价比试点阶段高约 20%。采购部门认为当前价格不能直接续签，要求在第二阶段立项前完成价格谈判和替代方案比选。

这一事项与模型效果没有直接关系，但会影响第二阶段是否能按原计划启动。
