# 合成Agent工具路由学习片段

> 教学合成工具描述，不是某真实代码仓库的实现与运行日志。

用户真正的问题：“Agent如何根据用户问题判断应该调用哪个工具？最小验证证据是什么？”

工具说明：
- `read_local_file(path)`：读取用户已上传的**本地文件**。
- `search_policy_library(query)`：搜索**制度库**并返回候选片段。
- `list_available_tools()`：给出当前允许的工具列表。

用户消息A：“请总结我刚上传的合同.pdf。” 用户消息B：“请找出知识库中最新的授信制度。” 用户消息C：“这份合同符合最新授信制度吗？”消息C通常需要把两类材料结合起来，不能预先断言某一工具一次就足够。

某Learning旧答案用了“模型调用read_local_file成功 → 工具返回文字 → Observation进入下一轮AgentLoop”的例子，声称已解答“Agent如何选择工具”。它**只说明已选工具如何执行**，没有提供工具选择环节、模型上下文里可见的工具声明、参数约束、权限检查或选择依据。

任务：评价这段Learning是否答到最初的研究问题；在不冒充真实运行或替模型编造内部推理的前提下，用上述不同用户任务展示何种选择输入及工具差异才能帮助识别选择机制，并说明需要什么真实的tool-call日志和上下文记录核查。
