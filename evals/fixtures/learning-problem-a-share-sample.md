# Learning 回归材料：上涨股研究为什么可能问错了问题

> 这是从2026年10月10日一次真实对话的研究产物重新整理的**训练摘要**，不是本次从交易所重新核验的数据；历史证券结论和研究观点仍应回查原始报告。禁止把材料用于推导真实证券交易建议或股票当天上涨的因果。

用户的任务：按收盘涨幅，分别从北交所、深交所、上交所选出前三及所有同时触及涨停上限的股票，排除当日上市新股；围绕样本搜集近三个月个股评论、广泛行业研究，然后用 SenseWright Learning 真正理解公司与行业。用户**没有**要求预测次日涨幅或对12家公司给买卖评级。

样本来自2026-10-09同一天涨幅较大的12家公司，涵盖不同经营方式。原研究将它们逐项写成“行业需求增长是否转化为收入/利润”的问句：

- **中文在线**：短剧/IP衍生品收入同比增长约108.72%，公司仍亏损；近三个月分析看好短剧增长，行业观察也提到AI制作降本和平台分账制约。
- **芒果超媒**：营业收入同比约+3.86%，归母利润同比约-73.58%，会员收入下滑。研究观点中仍有“增持”，但盈利预测被下修。
- **绿盟科技**：AI安全被认为是新市场，但公司上半年仍亏损；行业研究称很多AI安全项目仍处于POC。
- **东岳硅材**：利润同比大幅回升；有机硅产品售价、工业硅成本及供需周期影响重要。
- **力王股份**：总营收增长，但利润下滑；锂电池在营收中的比例不高，不能直接套用整个储能产业链景气叙述。

缺失的证据：内容平台真实获客成本、IP分账/议价；AI安全实收经常性费用；化工价差持续性与库存周期；锂电和传统产品分部利润。样本没有平盘/下跌公司对照，也没有能独立证实2026-10-09各只股票上涨原因的事件研究。

回归要检验的问题：Learning 是否识别**按涨幅选样只是取材条件，并不是研究问题**；能否发现不同公司表面上涨背后截然不同的经营变化、提出竞争的解释机制、选择更有信息价值的研究问题，并清楚限定原始证据能支持到什么程度？不能为了显示深刻把所有企业强行归为同一种“资本效率问题”。
