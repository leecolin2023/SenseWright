# 学习场景：银行业务部门“不愿意用 Agent”

当前只有用户自己的概括性观察：

> “我们银行很多业务部门其实不愿意用 Agent。”

当前尚未确认：

- “不愿意用”是指不愿采购、不愿试用、使用频率低，还是不愿让 Agent 执行真实业务动作；
- 这是一个具体项目中的事实、多个访谈的共同结论，还是用户的总体感受；
- 是否存在一个真实的被拒绝、停用、低使用率或禁止执行动作的案例；
- 当前没有足够信息判断原因究竟是安全、权限、责任、效果、成本、组织流程还是其他因素。

这个材料故意不提供原因。Learning 应先判断当前 Knowledge Model 缺的是什么；如果最合适的信息源是用户，应通过一个中性 probe 获取关键信息，而不是凭常识补原因。
